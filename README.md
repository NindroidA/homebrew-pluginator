# 🍺 Homebrew Tap for Pluginator

## Install

```sh
brew tap NindroidA/pluginator
brew install pluginator
```

## Upgrade

```sh
brew upgrade pluginator
```

## About

This tap is automatically updated on every [Pluginator release](https://github.com/NindroidA/pluginator/releases).

For more information, see the [main repository](https://github.com/NindroidA/pluginator).
